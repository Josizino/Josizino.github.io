Project Ejay

In development

Early-stage ransomware detection system

A prototype designed to detect ransomware activity before file encryption begins. It combines behavioral analysis of system, file, and process events with machine learning classification to separate normal activity from likely-malicious activity at the earliest observable stage.

  • Monitors system, file, and process behavior in real time
  • Python classification model trained to surface anomalous patterns
  • Pre-encryption detection window, targeting intervention before data loss
